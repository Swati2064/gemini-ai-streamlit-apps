# 🚀 Gemini API Tutorial

## 📖 About

This project demonstrates how to use the **Google Gemini API** with **Python** in a Jupyter Notebook. It includes basic examples of generating AI responses using Gemini models and is intended for beginners who want to learn Generative AI.

---

## ✨ Features

* Google Gemini API Integration
* AI Text Generation
* Prompt-based Responses
* Python Implementation
* Jupyter Notebook Examples

---

## 🛠️ Technologies Used

* Python
* Google Gemini API
* Jupyter Notebook
* python-dotenv

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/swati2064/gemini-api-tutorial.git
```

2. Move into the project folder:

```bash
cd gemini-api-tutorial
```

3. Install the required packages:

```bash
pip install -r requirements.txt
```

---

## 🔑 Configure API Key

Create a `.env` file and add your Gemini API key:

```env
GOOGLE_API_KEY=YOUR_GEMINI_API_KEY
```

> **Note:** Do not upload your `.env` file to GitHub.

---

## ▶️ Run the Project

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open the notebook:

```text
gimini_intro.ipynb
```

Run the notebook cells one by one.
