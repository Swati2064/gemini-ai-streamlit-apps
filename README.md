# 🚀 Gemini AI Streamlit Applications

A collection of **Generative AI applications** built using **Google Gemini API**, **Python**, and **Streamlit**. This repository demonstrates different Gemini AI capabilities, including text generation, conversational chat, chat history management, and image understanding.

---

## 📌 Features

* 💬 AI Question & Answer Chatbot
* 🤖 Interactive Gemini Chat Application
* 📝 Chat History Management
* 🖼️ Image Understanding with Gemini Vision
* ⚡ Fast and Interactive Streamlit Interface
* 🔐 Secure API Key Management using `.env`

---

## 🛠️ Technologies Used

* Python
* Streamlit
* Google Gemini API
* Python Dotenv
* Pillow (PIL)
* IPython

## 📖 Applications Included

### 1. Gemini Q&A Application

A simple AI-powered question-answering application built with Streamlit and Google Gemini.

**Features**

* Ask any question
* Get AI-generated responses
* Clean Streamlit interface

Run:

```bash
streamlit run app.py
```

---

### 2. Gemini Chat Application

An interactive chatbot that maintains a live conversation with the user.

**Features**

* Continuous conversation
* Streaming responses
* Easy-to-use interface

Run:

```bash
streamlit run chat.py
```

---

### 3. Gemini Chat History Application

A chatbot that stores previous conversations during the session.

**Features**

* Conversation history
* Session state management
* Better user experience

Run:

```bash
streamlit run qachat.py
```

---

### 4. Gemini Vision Application

Upload an image and ask questions about it using Gemini's multimodal capabilities.

**Features**

* Image upload
* Image analysis
* Visual question answering

Run:

```bash
streamlit run vision.py
```

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/swati2064/gemini-ai-streamlit-apps.git
```

Move into the project folder.

```bash
cd gemini-ai-streamlit-apps
```

Install the required packages.

```bash
pip install -r requirements.txt
```

---

## 🔑 Configure API Key

Create a `.env` file in the project directory.

```env
GOOGLE_API_KEY=YOUR_GEMINI_API_KEY
```

> **Note:** Never upload your `.env` file to GitHub.

---

## ▶️ Run the Application

Choose any application.

```bash
streamlit run app.py
```

or

```bash
streamlit run chat.py
```

or

```bash
streamlit run qachat.py
```

or

```bash
streamlit run vision.py
```
